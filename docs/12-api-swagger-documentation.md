# ClimaSentinel API Documentation (Swagger Reference)

This document provides a clean, human-readable reference of the ClimaSentinel REST API endpoints. It is derived from the interactive Swagger (OpenAPI) documentation generated by the FastAPI backend.

## Base Information
- **Framework**: FastAPI (Python)
- **Base URL**: `http://127.0.0.1:8000` (Local Development)
- **Content-Type**: `application/json`

---

## 1. General & System Endpoints

### `GET /`
- **Tags:** General
- **Description**: Welcome endpoint and service routing information.
- **Response** (200 OK):
  ```json
  {
    "service": "ClimaSentinel",
    "version": "1.0.0",
    "docs": "/docs"
  }
  ```

### `GET /health`
- **Tags:** General
- **Description**: Health check endpoint for load balancers and container monitoring (e.g., Railway/GCP).
- **Response** (200 OK):
  ```json
  {
    "status": "healthy",
    "environment": "production",
    "uptime_seconds": 120.5
  }
  ```

---

## 2. BigQuery Data & Analytics Endpoints

### `GET /data/current-scores`
- **Tags:** Data
- **Description**: Retrieves the current tipping scores for monitored cities from the `mart_city_score_current` table.
- **Query Parameters**:
  - `limit` (integer, default: 10): Maximum number of cities to return.
- **Response** (200 OK): Array of city scores.
  ```json
  [
    {
      "city_id": "paris_fr",
      "current_tipping_score": 42.5,
      "current_primary_driver": "Heat"
    }
  ]
  ```

### `GET /data/history-scores`
- **Tags:** Data
- **Description**: Retrieves historical tipping scores.
- **Query Parameters**:
  - `city_id` (string, optional): Filter by a specific city (e.g., `paris_fr`).
  - `limit` (integer, default: 50): Maximum number of records to return.

### `GET /data/current-zones`
- **Tags:** Data
- **Description**: Retrieves current tipping zones and boundaries from `mart_city_zone_current`.
- **Query Parameters**:
  - `limit` (integer, default: 20): Maximum number of zones to return.

## 3. Granular Risk & AI Forecasting Endpoints

### `GET /data/city/{city_id}/scores`
- **Tags:** Data
- **Description**: Returns individual tipping sub-scores (heat, wind, rain, air, river) for a specific city within the current 48-hour operational window.
- **Path Parameters**:
  - `city_id` (string, required): The unique identifier for the city (e.g., `paris_fr`).
- **Response** (200 OK):
  ```json
  {
    "city_id": "paris_fr",
    "current_tipping_score": 42.5,
    "current_primary_driver": "Heat",
    "heat_score": 60.0,
    "wind_score": 20.0,
    "rain_score": 10.0,
    "air_score": 50.0,
    "river_score": 5.0
  }
  ```

### `GET /data/city/{city_id}/forecast`
- **Tags:** Data
- **Description**: Returns the **3-day future climate tipping forecast** using the Multi-Output Random Forest model. It extracts weather trajectories, runs inference, and computes dynamic 95% Confidence Intervals based on tree-level variance.
- **Path Parameters**:
  - `city_id` (string, required): The unique identifier for the city (e.g., `paris_fr`).
- **Response** (200 OK):
  ```json
  {
    "city_id": "paris_fr",
    "prediction_date": "2026-06-30",
    "current_tipping_score": 42.5,
    "estimated_total_tipping_score": 65.2,
    "total_confidence_margin": 4.1,
    "total_ci_lower": 61.1,
    "total_ci_upper": 69.3,
    "forecast_primary_driver": "Heat",
    "sub_scores_forecast": {
      "heat_score": {
        "estimated_score": 65.2,
        "ci_lower": 61.1,
        "ci_upper": 69.3,
        "confidence_margin": 4.1
      }
      // ... (includes wind, rain, air, river)
    },
    "weather_trajectory_3d": {
      "temp_max_plus_1d": 32.5,
      "temp_max_plus_2d": 34.1,
      "temp_max_plus_3d": 35.8,
      "precip_plus_3d": 0.0,
      "wind_plus_3d": 15.2
    }
  }
  ```
